Python

Beginner-friendly Python: the small mistakes everyone makes, explained one at a time.

Why b = a does not copy a list

Assigning a list to a new name only makes a second label for the same list. Use copy() to get a real copy.

Code from this video 
# b = a does NOT copy the list
a = [1, 2, 3]
b = a          # b is just another name for the same list
b.append(4)
print(a)       # [1, 2, 3, 4]  - a changed too!

# the right way
b = a.copy()   # a real, separate copy
b.append(5)
print(a)       # [1, 2, 3, 4]  - a is safe now

Where did 5 go in range(1, 5)?

range() stops one step before the end value. range(1, 5) gives 1, 2, 3, 4 - never 5.

Code from this video 
print(list(range(1, 5)))   # [1, 2, 3, 4]
print(list(range(5)))      # [0, 1, 2, 3, 4]

# want 1 to 5? go one past it
for i in range(1, 6):
    print(i)               # 1 2 3 4 5

Why is -7 // 2 = -4?

Floor division rounds down, and "down" with negatives means away from zero.

Code from this video 
print(7 / 2)    # 3.5   (normal division)
print(7 // 2)   # 3     (floor division rounds down)

print(-7 // 2)  # -4, not -3
# -3.5 rounded DOWN is -4

Why does 5 + 2 become 52?

input() always gives you text. "5" + "2" sticks together as "52". Convert with int() first.

Code from this video 
a = input("First number: ")   # "5" - text, not a number
b = input("Second number: ")  # "2"
print(a + b)                  # 52  (text joined)

a = int(input("First number: "))
b = int(input("Second number: "))
print(a + b)                  # 7   (real addition)

Why scanf cannot read a full name

%s stops at the first space, so "Aman Kumar" becomes just "Aman". Here is the fix.

Code from this video 
#include <stdio.h>

int main() {
    char name[50];

    // stops at the first space
    scanf("%s", name);

    // reads the whole line, spaces included
    scanf(" %49[^\n]", name);

    printf("%s", name);
    return 0;
}

12 / 0 = Infinity?

JavaScript does not crash on division by zero. It quietly answers Infinity. Try it in your browser console.

Code from this video 
console.log(12 / 0);   // Infinity
console.log(-12 / 0);  // -Infinity
console.log(0 / 0);    // NaN (not a number)
